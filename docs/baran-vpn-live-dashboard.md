# Baran VPN live dashboard

The Baran VPN home dashboard now includes:

- ON state inside the power control while connected.
- Country-level world boundaries from Natural Earth 1:110m data.
- Source-network and VPN-exit country highlighting based on public-IP GeoIP coordinates.
- A live upload/download traffic graph based on Xray outbound traffic counters.

GeoIP locations are approximate public-IP locations and are not device GPS coordinates. Country boundaries are cartographic representations. The source dataset is public domain; see `V2rayNG/app/src/main/assets/WORLD_MAP_DATA_NOTICE.txt`.
